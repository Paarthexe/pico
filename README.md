# Pico

**Pattern Investigation and Computational Observation agent**

A hypothesis-driven CSV analyst with a Streamlit workspace. Pico profiles an unfamiliar dataset, selects an investigation, evaluates the evidence, and uses the result to choose a follow-up. Every finding links to a completed statistical analysis.

## Milestones

1. Profiling, validated analysis tools, and evidence records.
2. Adaptive planner, bounded investigation loop, and reproducible exports.
3. Streamlit workspace, demo dataset, and validation.

Implementation and setup instructions will be added with each milestone.
