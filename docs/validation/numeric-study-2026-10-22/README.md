# Numeric methods and study context

Date: 2026-10-22. Implementation began in `157a9a7`.

## Verified numeric recipes

| Recipe | Effect | Pointwise 95% interval | Scope |
| --- | --- | --- | --- |
| `pearson_r` | Pearson correlation r | Fisher-z transform | Two original numeric columns; no rank transform |
| `welch_t` | Mean(second group) − mean(first group) | Welch/Satterthwaite t | Exactly two string-sorted groups and numeric outcome |
| `ols_simple` | Slope of outcome per predictor unit | Classical t interval, n−2 df | One numeric predictor, fitted intercept |

All recipes use original pairwise complete cases. The host checks n, summary rows, statistic and p-value; optional model effects and CI bounds must match. A missing effect or interval is computed by trusted code, not inferred from prose. Uncertainty remains model-based: Pearson inference assumes independent bivariate-normal samples; Welch small-sample inference requires appropriate group distributions; classical OLS requires independent homoskedastic normal errors and a suitable linear mean relationship. Assumptions are surfaced in the UI/report, not asserted to hold. Pointwise intervals are not corrected for multiple testing or adaptive selection.

Degenerate, nonfinite, nearly constant and undersized inputs are rejected. These recipes do not verify rank correlations, adjusted/multivariable regression, logistic regression, or repeated-measures/cluster/time-series methods. Existing contingency recipes are retained; they do not gain validated effect-size intervals from this change.

## Study declarations and enforcement

The expandable Study context form accepts subject ID, observation timestamp, outcome timestamp, and post-outcome columns. It reuses native Streamlit controls and the existing style lock; the mobile form stacks labels/inputs without horizontal overflow.

All role columns are excluded from catalog predictors and follow-up controls; generated proposals cannot choose them as predictors. Post-outcome columns are physically withheld from sandbox input and safe replay scripts. Declared subjects and timestamps remain in the original audit data, not silently treated as covariates. Conflicting/missing roles are rejected. Declarations affect the settings signature and reset when the dataset changes.

Repeated subject rows, missing subject IDs, invalid/numeric timestamps, and observations at/after the outcome suppress independent-row inferential adjustment and interval display. Arithmetic/effects may still be descriptive. Valid chronology does not prove lack of temporal dependence or feature availability; a timestamp warning remains. This is context-aware suppression, not automatic cluster adjustment or causal identification.

## Validation

129 Python tests pass locally, including 11 actual Docker tests. Added cases compare numeric estimates and bounds to SciPy references, OLS bounds to a separate design-matrix calculation, reject fabricated summaries/p-values/effects/intervals, and check chronology, repeated subjects, role conflicts, state invalidation, actual withheld executor input, and replay exclusions.

Seven isolated Chromium browser tests pass, including mobile/desktop study panels, WCAG A/AA scans, existing report download, and responsive views. A follow-up capture of the complete study panel was visually reviewed at 390px and 1280px. No new palette, fonts, or motion were introduced. The generic design scanners do not parse Python UI source; those runs scanned zero files and are not claimed as coverage. Browser checks are not a full accessibility certification.

The [live Ollama smoke test](summary.json) used `qwen2.5-coder:7b`, actual Docker and 120 seeded numeric observations. Both executions matched Pearson r≈0.7444 and the host computed 95% bounds ≈[0.6522, 0.8149]. The model repeated the same comparison with different source, so this is one analysis smoke test, not two independent investigations or a broader real-world evaluation. Both reports were conservatively retained in the Holm family. Original source snapshots are `.py.txt`; [the effect plot](checked-effect.png) was generated by trusted host code and visually checked. Model/image digests and timings are retained in the summary. Minor report/browser changes were in progress; the numerical implementation was committed in `157a9a7`.

This work implements method verification and user-provided study context only. A broader real-world/repeated-run model benchmark was intentionally outside this request.
